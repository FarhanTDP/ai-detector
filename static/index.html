      Text analytics

      How scoring works
      • Scans need at least 300 words.
      • Text is split into overlapping ~500-word windows.
      • Each window is scored on the GPU by two DeBERTa-v3 detectors; a window only counts as AI if both agree. The document score is the average across windows.
      • Under 20%, the result is shown as Human-Written and the exact score is withheld.
      • Smaller overlapping windows localise the score to each section. If a long passage is strongly AI-like, the document is flagged even when the rest reads as human.
      • Detectors are probabilistic — treat results as a signal, not proof.
